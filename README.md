# 벤틀리 보급고 — 개인용 뽑기 시뮬레이터

원본 표지를 사용하는 무료 개인용 웹사이트입니다. 설치, API 키, 계정, 결제 없이 실행됩니다.

## 바로 실행

1. ZIP을 **먼저 압축 해제**합니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. **1개 열기 / 10개 열기**를 누릅니다.

화면은 게임처럼 16:9 비율을 유지합니다. PC 전체 화면(F11)을 권장합니다. 휴대폰에서는 가로 화면으로 이용하세요.

Node.js가 설치되어 있다면 `npm start`로 실행한 뒤 `http://127.0.0.1:4173`을 열어도 됩니다. 패키지 설치는 필요 없습니다.

## 포함된 기능

- 원본 표지, 사용자 제공 사진에서 잘라낸 아이템 66개
- 영상에서 추출한 황금·은색·갈색 카드 뒷면과 창고 장면
- 상자: 레전더리 이상 포함 시 금빛 연출, 그 외 일반 연출
- 10개 결과 카드 개별 열기 / 모두 열기
- 얼티밋: 처음에는 황금 카드 → 추가 분홍색 연출 → 아이템 공개
- 공식 확률의 독립 추첨, 누적 토큰과 보상 수령, 특수 제작
- 획득 내역, 최근 200회 기록, 브라우저 자동 저장, JSON 내보내기·가져오기
- 연출 미리보기(실제 추첨 및 저장 기록과 분리), 빠른 연출, 효과음 끄기, 움직임 줄이기
- 없는 이미지는 **꽝** 표시. 해당 보상의 이름·등급·확률은 원래대로 유지

## 조작

| 키 | 동작 |
|---|---|
| SPACE | 상자 건너뛰기 / 모두 열기 / 특별 공개 계속 |
| 1–9, 0 | 1–10번째 카드 열기 |
| ESC | 창 닫기 / 보급고로 돌아가기 |

카드를 공개하기 전에 보급고로 돌아가거나 새로고침해도 결과가 바뀌지 않습니다. 개봉 시작 시 결과와 보상을 한 번만 저장합니다. ‘연출 미리보기’에서는 기록과 재화를 변경하지 않습니다.

## GitHub에 올리기

이 폴더의 **내용 전체**를 저장소에 올리면 됩니다. `index.html`이 저장소 최상위에 있고 `assets/`의 경로가 유지되어야 합니다. `node_modules`나 빌드 작업은 필요 없습니다. 외부 CDN이나 폰트도 사용하지 않습니다.

혼자 사용하려면 비공개 저장소에 보관한 뒤 PC에서 실행할 수 있습니다. 이 전달물에서는 GitHub 업로드나 사이트 공개를 수행하지 않았습니다. 정적 웹 호스팅에서도 동일한 폴더 구조로 사용할 수 있습니다.

## 확률과 구현 범위

- 기준: PUBG #43.2, **2026-10-14** 공개 표 (2026-10-16 확인)
- 공식 벤틀리 화물 **129행**, 합계 **100.000%**
- 공식 출처: https://www.pubg.com/ko/game-info/probability/pc/11231
- 제작 및 누적 보상 출처: https://bbs-pubg.kakaogames.com/gaia/do/pubg/gm/read?articleId=1324&bbsId=PN002&objCate1=253
- 차량 도안: 럭셔리 세단 0.15%, 일반 세단 0.20%, GTC 0.25%
- 1회마다 벤틀리 토큰 15개. 게임과 같은 확률로 추첨하며 확률 보정이나 숨은 천장은 없습니다.
- 내부 확률은 0.001% 단위의 정수 가중치로 합산합니다. 가능한 브라우저에서는 `crypto.getRandomValues`를 사용합니다.
- 연출 색상은 요청에 맞춘 단순화입니다: 얼티밋=황금 후 분홍, 레전더리=황금, 에픽·엘리트=은색, 레어·스페셜·재화=갈색.
- 게임의 3D 렌더링을 복제한 것이 아니라 원본 이미지와 CSS/Canvas로 연출을 재현했습니다. 게임 전체 메뉴, 패스, 일반 제작, 분해, 실시간 차량 회전 기능은 포함하지 않습니다.
- 재화는 시뮬레이터 전용입니다. 무료 개봉에는 제한이 없으며 가상 G-COIN 사용량만 집계합니다. 획득한 화물 티켓도 수집 기록으로 보관합니다.
- 도안 획득과 토큰 특수 제작 내역은 별도로 표시합니다. 누적 보상에 제공되지 않은 이미지는 꽝으로 표시됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 원본 배치, 개봉·카드·분홍색 연출 |
| `app.js` | 화면 전환, 효과음, 저장, 제작, 인벤토리 |
| `data.js` | 공식 확률과 아이템 이미지 대응, 제작·누적 보상 |
| `core.js` | 추첨 및 저장 상태 처리 |
| `assets/` | 제공된 이미지와 영상에서 추출한 정적 이미지 |
| `server.cjs` | 선택 사항인 로컬 미리보기 서버 |
| `tests/core.test.cjs` | 확률 경계·중복 지급 방지·저장 복원 테스트 |

## 저장

설정 → **저장 파일 내보내기**로 백업할 수 있습니다. 다른 브라우저, 시크릿 모드, 파일 위치 변경, 브라우저 데이터 삭제 시 기존 저장이 유지되지 않을 수 있으므로 이동 전에 내보내기를 사용하세요. 저장이 제한되는 환경에서는 하단에 상태가 표시됩니다.

Node.js 환경에서 `npm test`를 실행합니다. 외부 의존성은 없습니다.
